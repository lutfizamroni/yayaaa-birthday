# Yayakkkk Interactive Birthday Website

Versi revisi: flower mini-game diperbaiki agar drag & drop bekerja di mouse maupun touchscreen, dan setiap slide memiliki gerakan Nailong yang berbeda menggunakan CSS animation.

## Jalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Untuk HP, upload folder ke hosting statis (GitHub Pages / Netlify / Vercel) lalu jadikan URL sebagai QR Code.

## Foto
Masukkan foto pribadi ke `assets/photos/` dengan nama:
- foto-1.jpg
- foto-2.jpg
- foto-3.jpg
- foto-4.jpg
- foto-5.jpg
- foto-6.jpg

## Musik
File MP3 yang kamu berikan sudah disertakan. Browser biasanya baru mengizinkan audio setelah interaksi pengguna; karena itu musik dimulai saat tombol hadiah disentuh atau tombol musik ditekan.

## Nailong
Animasi Nailong dibuat dengan CSS/HTML lokal agar website tidak bergantung pada hotlink gambar Pinterest. Referensi visualnya mengikuti ciri umum Nailong yang populer: bentuk bulat, warna kuning, perut putih, ekspresi polos dan gerakan kecil yang menggemaskan.


### Foto 1–6
Kartu memori menggunakan crop cerdas per foto agar wajah tetap terlihat jelas tanpa membuat komposisi foto terasa miring atau terpotong di bagian wajah. Posisi crop diatur khusus untuk setiap foto.
